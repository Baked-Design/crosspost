# Security

Crosspost runs entirely in your browser. There is no Crosspost server and no account with us.

- Your LinkedIn Client ID, Client Secret, login token and optional Anthropic key are saved in Chrome's local extension storage on your machine only. They are never synced and never sent anywhere except the service they belong to (LinkedIn, Anthropic).
- The extension only talks to x.com, twitter.com, pbs.twimg.com (your post images), linkedin.com and, if you add a key, api.anthropic.com.
- It only posts after X confirms your post went out, and you can review, edit or cancel every post.

## Reporting a problem

Please don't open a public issue for security problems. Use GitHub's "Report a vulnerability" button on the Security tab of this repo, and we'll get back to you.
